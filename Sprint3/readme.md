# ✨ Peça Rara – Sistema de Gestão Web (Sprint 3)

Este repositório apresenta o desenvolvimento da **Sprint 3** do projeto *Peça Rara Brechó*, realizado em parceria com a empresa Eclypse Tech.  
A entrega contempla a implementação da lógica de programação do sistema, integração com o banco de dados e finalização das funcionalidades essenciais, utilizando **PHP**, **MySQL**, **HTML5**, **CSS3** e **Bootstrap** para garantir uma aplicação responsiva e funcional.

O sistema foi desenvolvido com o objetivo de modernizar o processo administrativo da loja, substituindo controles manuais por uma plataforma web eficiente, segura e intuitiva.

---

## 📌 Objetivo da Sprint 3

A Sprint 3 teve como principal propósito transformar as telas estáticas criadas anteriormente em um sistema totalmente funcional, assegurando:

- Execução das operações de cadastro e listagem.
- Implementação do login com validação de credenciais.
- Aplicação das regras de negócio do brechó.
- Validação completa das funcionalidades desenvolvidas.

## ⚙️ Funcionalidades Implementadas

### 🔑 Login
- Autenticação do usuário com validação de e-mail e senha.  
- Controle de sessão para garantir acesso apenas após login bem-sucedido.  

### 📇 Cadastro de Fornecedores
- Inserção de nome, CPF/CNPJ, endereço, contato e observações.  
- Função para editar registros existentes.

### 📦 Cadastro de Produtos
- Inserção de nome, fornecedor, preço, quantidade e demais informações.  
- Validação de campos essenciais.  
- Associação correta ao fornecedor selecionado.

### 📋 Listagem de Produtos
- Exibição automática dos itens cadastrados.  
- Atualização em tempo real após novos cadastros ou edições.

## 🧪 Testes Realizados

Durante a Sprint 3, foram conduzidos testes voltados à confiabilidade e usabilidade do sistema:

### ✔ Testes de Cadastro
- Inserção de produtos e fornecedores.  
- Verificação de preenchimento obrigatório e retorno do sistema.

### ✔ Testes de Login
- Tentativas com credenciais válidas e inválidas.  
- Checagem de redirecionamento e mensagens de erro.

### ✔ Testes de Responsividade
- Ajustes de exibição em dispositivos móveis, tablets e desktops.  
- Correção de elementos desalinhados.

### ✔ Testes de Consistência
- Conferência da exibição dos registros cadastrados.  
- Validação da integridade dos dados apresentados.

---

## 📚 Conclusão

A Sprint 3 consolidou todas as etapas do projeto, conectando design, banco de dados e lógica de programação em um sistema funcional e coerente.  
O desenvolvimento permitiu aplicar conceitos fundamentais da programação web, fortalecer habilidades práticas e entregar uma solução alinhada às demandas do brechó Peça Rara.

A aplicação final apresenta desempenho consistente, boa organização visual e uma experiência de uso simplificada, adequando-se às necessidades reais da empresa e preparando terreno para futuras evoluções do sistema.
