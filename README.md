# Peça Rara Brechó – Sistema de Gestão de Produtos e Fornecedores

Este repositório contém o desenvolvimento da aplicação web criada para a empresa **Peça Rara Brechó**, em parceria com a **Eclypse Tech**, com o objetivo de modernizar processos internos, otimizar o gerenciamento de produtos e fornecedores e fortalecer a presença digital da organização.

---

## 📌 Descrição do Projeto

O sistema foi desenvolvido para substituir processos manuais baseados em planilhas e documentos físicos por uma solução web completa, dinâmica e eficiente.

A aplicação oferece funcionalidades como:

- Cadastro, edição, listagem e exclusão de produtos e fornecedores
- Sistema de login para controle de acesso
- Interface intuitiva, responsiva e padronizada
- Integração completa com banco de dados relacional MySQL

O projeto foi desenvolvido em três sprints, seguindo metodologias ágeis para garantir entregas contínuas, organização e evolução do sistema.

## 🔧 Como Executar o Projeto

**Pré-requisitos**

- PHP instalado (>= 7.4)
- MySQL ou XAMPP/WAMP
- Navegador atualizado
- Git (opcional)

**Passo a passo**

1. Clone este repositório:

```bash
git clone https://github.com/EclypseTech
```

2. Importe o banco de dados pelo arquivo `.sql` localizado na pasta `/Sprint3`.
3. Coloque o projeto dentro da pasta `htdocs` (XAMPP) ou `www` (WAMP).
4. Inicie o servidor Apache e o MySQL.
5. Acesse pelo navegador:

```
http://localhost/Sprint3/login/loginPage.php
```
